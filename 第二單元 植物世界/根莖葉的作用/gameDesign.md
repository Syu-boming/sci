# 角色與任務

你是資深前端工程師＋兒童教育遊戲設計師。請用「單一 index.html 檔」（HTML5 + CSS + 原生 JavaScript，CSS 與 JS 都內嵌，不使用框架）做一款給台灣國小五年級的教育小遊戲「植物醫生」，主題是植物「根、莖、葉」的功能。畫面所有文字使用繁體中文。

# 學習目標

玩家透過「診斷生病的植物」學會三件事並能實際應用：

- 根：吸收水分與養分、把植物固定在土裡
- 莖：運輸水分養分、支撐植株直立
- 葉：行光合作用製造養分
  玩家要能把「症狀」對應到出問題的「部位」，再選出正確「處置」。

# 遊戲玩法

- 關卡制，每關一個病例。
- 每關流程：顯示一株生病植物的圖＋症狀敘述 → 步驟一：從「根／莖／葉」三選一判斷問題部位 → 步驟二：從 3 個處置選項選正確療法 → 顯示對/錯回饋與科學原理說明，播放植物康復動畫 → 進入下一關。
- 兩步都答對該關才滿分；答錯給提示並可再試一次（再試會扣分）。
- 計分＋升級進度（例：實習醫生 → 見習醫師 → 植物醫師），全破後顯示總分與「再玩一次」。
- 大按鈕、大字體，同時適合平板觸控與教室投影。

# 關卡內容（請完全依照以下科學內容，勿自行更動正確答案）

案例1／缺光：症狀「這盆植物被放在房間陰暗角落兩週，葉子變黃，莖又細又長還往一邊倒。」正確部位＝葉。處置：①移到有陽光的窗邊（正確）②再多澆水 ③把葉子剪掉。原理：葉子要靠陽光行光合作用製造養分；長期缺光會黃化，植株還會為了找光而徒長變細長。

案例2／缺水：症狀「葉子全部下垂枯萎，土壤又乾又硬還裂開。」正確部位＝根。處置：①澆水（正確）②移到陰暗處 ③立支架。原理：根負責從土裡吸收水分，再經由莖送到全株；土太乾，根吸不到水，整株就缺水枯萎。

案例3／倒伏折莖：症狀「一株很高的向日葵被大風吹倒，莖彎折，上半部開始枯萎。」正確部位＝莖。處置：①立支架扶正固定（正確）②澆水 ③移到陽光下。原理：莖負責支撐植物直立，也把根吸收的水分養分往上運輸；莖折斷後運輸中斷，上方就會枯萎。

案例4／根部鬆動：症狀「植物搖搖晃晃站不穩，根部的土很鬆，還有幾條根露在外面。」正確部位＝根。處置：①把土培回壓實、固定根部（正確）②剪掉露出的根 ③噴殺蟲劑。原理：根除了吸水，也像錨一樣把植物固定在土裡；根沒被土包好，植物就站不穩。

案例5／蟲害：症狀「葉子被蟲咬得坑坑洞洞，幾乎只剩葉脈。」正確部位＝葉。處置：①除蟲並保護葉片（正確）②多澆水 ③立支架。原理：葉子是植物製造養分的工廠；葉子被吃光，植物無法行光合作用製造足夠養分，就會愈來愈虛弱。

請把關卡資料寫成一個 JS 陣列/物件集中管理，方便日後增減關卡。
