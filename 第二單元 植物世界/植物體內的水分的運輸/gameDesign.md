你是資深前端工程師＋兒童教育遊戲設計師。請用「單一 index.html 檔」（HTML5 + CSS + 原生 JavaScript，CSS 與 JS 都內嵌，不使用框架）做一款給台灣國小五年級的教育小遊戲「**水滴大冒險——植物體內的旅行**」，主題是植物「**水分與養分的運輸**」以及「**光合作用**」。畫面所有文字使用繁體中文。

# 學習目標

玩家跟著一顆有生命的「**小水滴**」旅行，走過植物體內的旅程，學會並能實際應用：

- **根**：從土壤吸收水分（水裡還溶著礦物質／養分），也把植物固定在土裡。
- **莖**：把根吸收的水往上運輸到葉子；也把葉子做好的養分往下、往各處運送。莖裡有像吸管一樣的運輸管道（**導管**）。
- **葉**：行**光合作用**——用【水＋二氧化碳＋陽光】製造【養分（糖）】，同時放出【氧氣】。
- **整體流程**：根吸水 → 莖往上送水 → 葉光合作用做養分 → 莖把養分送到全株（根、花、果實）。
- **延伸（輕量帶入，不強制操作）**：
  - 光合作用會**放出氧氣**（動畫呈現氧氣泡泡）。
  - **蒸散作用**：葉子把一部分水變成水蒸氣散到空氣中，像從上面幫忙把莖裡的水往上「拉」。
  - 根吸收的水裡**含有溶解的礦物質／養分**（旁白一句帶過）。

# 遊戲玩法

- **主角**：小水滴吉祥物（有臉、大眼微笑），全程當旁白＋講解者。植物與器官一律**圖鑑式無臉**。
- **畫面流程（四個畫面）**：① 標題 → ② 旅程（依序承載四站）→ ③ 結尾測驗 → ④ 結算。
- **旅程進度列**：畫面上方用「根 → 莖 → 葉 → 全株」四個點顯示目前站別（做法同〈植物醫生〉的進度點點 `dots`）。
- **每站流程**：出現該站場景與小水滴的任務說明 → 玩家完成一個簡單的**點擊／收集／合成**小任務 → 小水滴講解該站科學原理、給星星 → 「下一站」按鈕進入下一站。
- **結尾測驗**：3–5 題單選題檢核學習；答對加分並講解原理，答錯給提示可再試一次（再試扣分）。做法沿用〈植物醫生〉的選項按鈕與計分。
- **計分／頭銜**：用星星計分；依累計分數即時升級頭銜（見習小園丁 → 植物探險家 → 光合作用大師）。全破後結算顯示總分、頭銜與「再玩一次」。
- **操作**：大按鈕、大字體；**以「點擊」為主要互動**（教室平板觸控與投影最穩），拖放為輔；觸控目標要大。

# 關卡內容（四站 + 測驗，科學內容為正確答案，請勿自行更動）

> 每一站至少包含：場景、玩家任務（互動）、過關條件、小水滴旁白／原理、用到的素材檔名。請把四站資料與測驗題各寫成一個集中管理的 JS 陣列（見文末「建議資料結構」），方便日後增減。

## 第 1 站　根：吸收水分（＋礦物質）
- **場景**：土壤剖面，露出一條主根與許多**根毛**；土裡散布著水滴（部分水滴夾帶小小的礦物質顆粒）。素材：`stage-root-soil.png`、`item-water.png`、`item-mineral.png`。
- **任務（點擊收集）**：玩家點擊土裡的水滴，水滴會被根毛吸入、流進根部；上方「吸水量」進度條隨之上升。集滿進度條（約 6～8 顆）即過關。
- **過關條件**：吸水量達 100%。
- **小水滴旁白／原理**：「植物用**根**，特別是細細的**根毛**，從土裡吸收水分——水裡還溶著一點點**礦物質**（養分）喔！根也像錨一樣把植物固定在土裡。」
- **過關演出**：根部裝滿水、發亮，準備往上送。

## 第 2 站　莖：把水往上運輸
- **場景**：一段莖的剖面／側面，露出像吸管一樣的**導管**通道，頂端連著葉子。素材：`stage-stem.png`、`item-water.png`。
- **任務（節奏點擊）**：玩家點「往上送水 ↑」按鈕（或點莖底的水滴），水滴一顆顆沿導管上升到葉子，集滿葉子上方的水量。集滿即過關。
- **過關條件**：送達葉子的水量達標。
- **延伸（蒸散，動畫＋資訊卡，不強制操作）**：莖頂的葉片持續冒出小小的水蒸氣往上飄；跳出一張資訊卡：「葉子會把一部分水變成水蒸氣散到空氣中，這叫**蒸散作用**，它像從上面幫忙把莖裡的水往上『拉』。」
- **小水滴旁白／原理**：「莖裡面有像吸管一樣的『**導管**』，把根吸收的水一路往上送到葉子。」
- **過關演出**：水送達葉子，葉子鼓起水珠。

## 第 3 站　葉：光合作用（★核心）
- **場景**：一片大葉子＝「**食物工廠**」，三個材料入口——上方☀️陽光、旁邊灰色的二氧化碳、下方💧水（來自莖）。素材：`stage-leaf.png`、`item-sun.png`、`item-co2.png`、`item-water.png`、`item-nutrient.png`、`item-oxygen.png`。
- **任務（湊齊三材料 → 合成）**：玩家分別點擊／拖入**陽光、二氧化碳、水**三種材料到葉子工廠。**三樣到齊**後，「行光合作用！」按鈕才會亮起；按下 → 葉子發光 → 產出**養分（糖）**包裹，同時冒出**氧氣**泡泡往上飄。重複 2～3 輪做足養分即過關。
- **規則（重要）**：三種材料**缺一不可**。若只湊到兩樣就想合成，工廠不啟動，小水滴會提示還缺哪一樣（強化「光合作用需要三樣東西」的概念）。
- **過關條件**：做出足夠份數的養分。
- **小水滴旁白／原理**：「葉子是植物的**食物工廠**！它用【水＋二氧化碳＋陽光】行**光合作用**，做出【**養分**】，同時放出【**氧氣**】。」
- **過關演出**：葉子上出現一堆養分包裹，氧氣泡泡陸續飄散。

## 第 4 站　莖：把養分送到全株
- **場景**：一整株植物（根、莖、葉、花苞、小果實），剛做好的養分包裹在葉子上。素材：`plant-cutaway.png` 或整株組合、`item-nutrient.png`、`part-flower.png`、`part-fruit.png`、`icon-part-root.png`。
- **任務（派送）**：玩家把養分包裹送到三個目的地——**根、花、果實**（點養分再點目的地，或點養分讓它沿莖自動送過去）。每個部位收到養分就會長大／開花／結果。全部送達即過關。
- **過關條件**：三個目的地都收到養分。
- **小水滴旁白／原理**：「莖不只把水往上送，也把葉子做好的**養分**往下、往各處送，讓根長得更壯、花開、果實長大！」
- **過關演出**：植物開花結果、變成茂盛健康的樣子（`plant-thriving.png`），星星噴發＋成功勳章（`ui-badge-success.png`）。

## 結尾測驗（3～5 題單選；沿用〈植物醫生〉選項按鈕與計分）
1. 植物用哪個部位從土裡吸收水分和礦物質？　根（✔）／莖／葉
2. 把根吸收的水往上送到葉子，是哪個部位的工作？　根／莖（✔）／葉
3. 光合作用需要哪三樣東西？　水、陽光、二氧化碳（✔）／水、土壤、氧氣／陽光、氧氣、養分
4. 葉子行光合作用時會放出什麼氣體？　氧氣（✔）／二氧化碳／水蒸氣
5. 葉子做好的養分，靠哪個部位送到根、花、果實？　根／莖（✔）／葉

每題：答對 → 加星星＋一句原理講解；答錯 → 該選項打叉停用、給提示、可再試一次（再試得分變少）。

# 技術要求

- **單一 index.html** 即可用瀏覽器直接開啟遊玩，不需後端、可離線。
- 原生 JavaScript、無框架；程式碼加上**繁體中文註解**方便老師自行修改。
- **資料驅動**：四站與測驗題集中在 JS 陣列／物件管理（見下），方便日後增減站數或題目。
- **響應式（RWD）**：平板直向與教室投影橫向都要好看；字級用 `clamp()`；觸控目標大。
- **音效**：以 Web Audio API 合成簡單提示音（吸水、送水、合成成功、答對、答錯、過關琶音），右上角有音效開關（可選，做法同〈植物醫生〉）。
- **過場動畫（CSS）**：水滴被吸入、水滴沿導管上升、葉子發光、氧氣泡上飄、養分派送、開花結果、星星噴發、蓋章、畫面淡入。
- 全程繁體中文、無錯字、瀏覽器 console 無錯誤。
