# 「植物身體的組成」素材生成指示書（給 Codex）

> 教學主題：植物身體的三個層次（細胞 → 器官 → 個體）與兩類器官（營養／繁殖），給台灣國小五年級。
> 使用情境：教室 **75 吋觸控螢幕**，全班共用、學生輪流上台操作。

## ⚠️ 本課美術風格與前兩課完全不同，請先讀這段

同資料夾的〈植物醫生〉和〈水滴大冒險〉是**扁平插畫風**。
**本課不是。本課全部要「真實照片風格」（photorealistic）。**

原因：這課要教「細胞、器官、個體」，是觀察與分類的課，不是遊戲。
學生必須看到真實的東西才能相信並辨認。**請不要畫成卡通、插畫或向量圖。**

## 1. 統一風格指示（每一張都要套用）

> 「真實照片風格，自然柔和的攝影棚光線，乾淨的純白或極淺灰背景，主體置中並佔滿畫面約
> 八成，淺景深但主體全部對焦清楚，色彩自然不過飽和，畫面中不要出現任何文字、標籤、
> 人手或器具。食材新鮮乾淨，不可有腐爛、發霉、蟲蛀或枯萎。」

**適齡要求**：畫面要乾淨、明亮、主體大而清楚，讓國小五年級學生一眼認得出來。
不要藝術性的裁切、不要昏暗氛圍、不要複雜佈景。

## 3. 輸出格式（重要）

- **一律存成 `.jpg`，不要 `.png`。** 這批是連續色調的照片，PNG 會讓檔案大好幾倍。
- 生成後請**縮到 600×600** 再存檔。
- JPEG 品質 **82**、開啟 optimize。單張目標 **40–90 KB**。
- **全部 12 張加起來請控制在 1 MB 以內。**
  （本站的素材有嚴格預算：前兩課的插畫壓縮後各約 0.4 MB。）

## 4. manifest.json 格式

沿用同資料夾其他兩課的欄位，並把已備妥的 4 張真實照片也一併列入（狀態標 `ok`、
`notes` 註明來源與授權）：

```json
[
  { "file": "organ-root.jpg", "title_zh": "器官卡：根", "category": "organ",
    "size": "600x600", "transparent": false, "status": "ok", "notes": "" },
  { "file": "zoom-plant.jpg", "title_zh": "放大鏡頭：個體（羅勒盆栽）", "category": "zoom",
    "size": "900x675", "transparent": false, "status": "ok",
    "notes": "真實照片，Wikimedia Commons, NeoMeesje, CC BY-SA 4.0，勿覆蓋" }
]
```

`category` 請用 `organ`（器官卡）、`veg`（餐桌蔬果）、`zoom`（放大鏡頭）、`cell`（顯微照片）。

## 5. 驗收標準

- 12 張全部產出、檔名與尺寸完全符合、總量 ≤ 1 MB
- **看起來是照片，不是插畫**
- 第 2、5、9、12 張的「必要細節」（節、種子、葉子、節）確實拍到
- 那 4 張真實照片原封不動
- 圖內無文字、無人手、食材新鮮
